# نسخه‌ی دمو — راهنمای اجرا و نمایش به مشتری

## اجرا (ویندوز)
1. Docker Desktop را باز کن.
2. یک بار (فقط اولین بار): `python tools\new-env.py`
3. دوبار کلیک روی **`start-dev.cmd`** — بعد از حدود ۱ دقیقه مرورگر روی `http://localhost:3000/login` باز می‌شود.

> نصب خالی (مثل مشتری واقعی، بدون داده‌ی نمونه): `start-empty.cmd`

## ورود سریع (فقط در دمو)
| دکمه | چه کسی | چه چیزی را نشان بده |
|---|---|---|
| ادمین | سارا (مدیر نمونه) | داشبورد و «راه‌اندازی قدم‌به‌قدم»، تابلوی کار، سفارش‌ها، مشتری‌ها و پکیج‌ها، حضور زنده‌ی تیم، تنظیم حضور، QR دفتر، برند و رنگ‌ها |
| تدوینگر | علی | فقط کارهای خودش، شروع کار ← تحویل برای بازبینی، تایمر، ورود و خروج |
| متن‌نویس | مریم | مثل بالا |
| مشتری | کافه نمونه | پکیج و سهمیه‌ی باقی‌مانده، «منتظر تأیید شما»، اصلاح لازم است، سفارش جدید |

## سناریوی ۱۰ دقیقه‌ای پیشنهادی
1. **ادمین** ← «سفارش‌ها» ← «سفارش جدید» برای کافه، خدمت «ریلز»، موضوع را بنویس ← ثبت. سه مرحله روی «تابلوی کار» می‌آید.
2. روی کارت ← «پیشنهاد: …» برای سپردن با یک لمس ← یک فایل آپلود کن ← پیام داخلی بنویس.
3. در یک پنجره‌ی دیگر (Incognito) با **تدوینگر** وارد شو ← «تابلوی کار» ← کارت «ریلز منوی پاییزه» ← «ارسال برای بازبینی». روی صفحه‌ی ادمین کارت **بدون رفرش** جابه‌جا می‌شود.
4. **ادمین**: روی همان کارت «نیاز به اصلاح دارد» با یادداشت، یا «ارسال برای تأیید مشتری».
5. **مشتری**: «منتظر تأیید شما» ← «تأیید می‌کنم» یا «اصلاح لازم است».
6. **تدوینگر/متن‌نویس** ← «حضور و ساعت» ← ورود ← استراحت ← تایمر روی یک کار ← خروج.
7. **ادمین** ← «حضور زنده‌ی تیم»: چه کسی سر کار است و روی چه کاری؛ «نیاز به بررسی» و «درخواست‌های اصلاح».
8. **ادمین** ← «QR دفتر» روی یک تبلت؛ همکار از صفحه‌ی حضور «اسکن QR دفتر» را می‌زند.
9. **نمای گوشی**: در Chrome کلید F12 ← آیکون گوشی (Toggle device toolbar). روی گوشی واقعی بعد از نصب روی سرور (آدرس دامنه) باز می‌شود؛ آیفون: Share ← Add to Home Screen.

## در دمو چه چیزی هنوز نیست
اپ اندروید نصبی (M7)، غیبت و مرخصی (M5)، یادآوری انتشار و ربات بله/تلگرام و پیامک (M6)، گزارش‌ها (M9)، بلاگ و سایت با سئوی خودکار (N9/N10)، گاوصندوق رمز پیج‌ها (N4).

## داده‌ها
همه‌ی اسم‌ها و قیمت‌ها **نمونه** هستند (پسوند «(نمونه)»). قیمت واقعی آژانس هرگز داخل کد نیست.
