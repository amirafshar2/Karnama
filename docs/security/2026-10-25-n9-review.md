# بررسی امنیتی N9 (بلاگ و ویرایشگر) — ۳ آبان ۱۴۰۵

| موضوع | نتیجه |
|---|---|
| XSS در متن پست | HTML فقط در سرور از JSON ساخته می‌شود؛ نود ناشناخته حذف، همه‌ی متن‌ها و ویژگی‌ها Encode (تست واحد با `<script>`، `javascript:`، `//evil.com`، `onerror`) |
| لینک‌ها | فقط http/https/mailto/tel یا مسیر داخلی؛ لینک بیرونی `rel="noopener noreferrer"` |
| عکس داخل متن | فقط از `/media/public/blog/{32hex}.(png|jpg|webp)`؛ عکس از دامنه‌ی دیگر حذف می‌شود |
| آپلود عکس | Magic Bytes (SVG/HTML رد — تست)، حداکثر ۲MB، نام تصادفی، سقف درخواست ۳MB |
| JSON-LD | `<` به `<` تبدیل می‌شود تا محتوا نتواند تگ script را ببندد |
| دسترسی | نویسنده (`blog.write:Own`) فقط پیش‌نویس‌های خودش را می‌بیند و ویرایش می‌کند؛ پست منتشرشده را فقط ویراستار تغییر می‌دهد؛ انتشار فقط `blog.publish` (تست ۴۰۳)؛ مشتری هیچ دسترسی ندارد (تست) |
| همزمانی | ویرایش با نسخه‌ی رکورد؛ نسخه‌ی کهنه = ۴۰۹ (تست) |
| API عمومی | فقط پست‌های منتشرشده (پیش‌نویس ۴۰۴ — تست)؛ متن خام JSON، نویسنده‌ی داخلی و پیش‌نویس‌ها بیرون نمی‌روند |
| JSON خراب یا خیلی بزرگ | حداکثر ۱MB و عمق ۶۴؛ JSON خراب = ۴۲۲ (تست) |
| مارک‌داون چسبانده‌شده | Markdig با HTML خاموش + Sanitizer |
| ریدایرکت نامک | فقط به نامک یک پست منتشرشده در همین سایت (Open Redirect ممکن نیست) |
| robots | پنل، ورود و API در robots.txt بسته؛ صفحه‌های پنل `noindex` |

**تغییر جانبی (کارایی):** صفحه‌ی ۴۰۴ کل Providerها را در همه‌ی صفحه‌ها بار می‌کرد (۹KB اضافه)؛ حالا سمت سرور و بدون JavaScript است. Providerها فقط برای پنل (`app/(app)/layout.tsx`)؛ سایت عمومی بدون آن‌ها.

یافته‌ی High/Critical: **ندارد**.
