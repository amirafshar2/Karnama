# بررسی امنیتی N10 (سایت عمومی، نمونه‌کارها، فرم مشاوره) — ۳ آبان ۱۴۰۵

| موضوع | نتیجه |
|---|---|
| فرم مشاوره (عمومی) | محدودیت ۵ درخواست در ۱۰ دقیقه برای هر IP، فیلد تله برای ربات، اعتبارسنجی شماره، یک درخواست برای هر شماره در ساعت (تست) |
| رضایت‌نامه‌ی نمونه‌کار | در پوشه‌ی خصوصی `consent/`؛ مسیر عمومی `/media/public` آن را باز نمی‌کند (تست ۴۰۴)؛ فقط `content.manage` (تست ۴۰۳ برای دیگران)؛ `Cache-Control: no-store` |
| انتشار نمونه‌کار | بدون رضایت و فایل آن رد می‌شود (تست)؛ پس گرفتن رضایت = برداشته شدن از سایت؛ درآمد «فقط درصد» مبلغ را در API عمومی نمی‌فرستد (تست) |
| اعداد اعتماد | فقط از داده‌ی واقعی؛ نمونه‌های دمو در میانه‌ی رشد حساب نمی‌شوند (تست) |
| محتوای صفحه‌ی اصلی | فقط `content.manage` (تست ۴۰۳)؛ عنوان و توضیح سئو اجباری با طول مجاز (تست ۴۲۲)؛ لینک نشان/بلد فقط https |
| JSON-LD | `<` Escape می‌شود؛ متن‌ها از پنل ولی فقط داخل JSON |
| درخواست‌های مشاوره | فقط `leads.manage`؛ شماره‌ها فقط برای همین نقش |
| کش عمومی | پاسخ‌های عمومی ۳۰ ثانیه در API کش و با هر تغییر محتوا پاک می‌شوند؛ این مسیرها از محدودیت عمومی معاف‌اند (سرور Next از یک IP می‌خواند) ولی فقط خواندنی‌اند |
| تداخل مسیر | صفحه‌ی عمومی پکیج‌ها `/plans` است تا با `/packages` پنل (که در robots بسته است) قاطی نشود |

یافته‌ی High/Critical: **ندارد**.
