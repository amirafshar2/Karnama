# بررسی امنیتی N4 (گاوصندوق رمز، پروفایل مشتری، پیام‌های پایان پکیج) — ۳ آبان ۱۴۰۵

| موضوع | نتیجه |
|---|---|
| ذخیره‌ی رمز | رمزنگاری پوششی: برای هر رکورد یک کلید تصادفی AES-256-GCM؛ آن کلید با کلید اصلی (`Vault__MasterKey`، بیرون از دیتابیس) بسته می‌شود. شناسه‌ی رکورد «داده‌ی همراه» (AAD) است: رمزِ کپی‌شده روی ردیف دیگر باز نمی‌شود (تست) |
| کلید اصلی | فقط متغیر محیطی؛ Production بدون کلید معتبر بالا نمی‌آید (StartupGuard)؛ چرخش کلید با `Vault__KeyVersion` و `Vault__PreviousKeys__{n}` (تست واحد)؛ در Development فایل تصادفی `storage/.vault-dev.key` بیرون از گیت. بکاپ دیتابیس به‌تنهایی رمزی را باز نمی‌کند |
| دیدن رمز | فقط `credentials.reveal` + کد پیامکی تازه به موبایل خود کارمند (نه مشتری)؛ کد ورود به کار دیدن رمز نمی‌آید و برعکس (ستون `Purpose`)؛ یک بار مصرف، ۵ تلاش، ۲ دقیقه؛ بدون کد → رد، با کد → موفق + Audit `credentials.revealed` + اعلان مهم به مالک (تست) |
| نمایش | ۳۰ ثانیه، با رفتن از تب فوراً پنهان؛ پاسخ `Cache-Control: no-store`؛ رمز در فهرست‌ها، Excel، لاگ و DTOهای دیگر نیست (`ToString` رکوردهای رمز `***` است) |
| کارگر | نه فهرست، نه شروع دیدن، نه دیدن (تست ۴۰۳) |
| مشتری | فقط حساب‌های خودش؛ رکورد مشتری دیگر → ۴۰۴ (تست)؛ فقط‌نوشتنی: رمز ذخیره‌شده دوباره به خود مشتری هم نشان داده نمی‌شود (تست)؛ تغییر هر فیلد جدا (فیلد خالی = همان قبلی) |
| حذف | حذف واقعی (نه نرم)؛ «پاک کردن رمز» ردیف را نگه می‌دارد و رمز را صفر می‌کند (تست) |
| محدودیت | کد دیدن رمز: ۹ پیامک در ۱۰ دقیقه برای هر کارمند + محدودیت IP؛ تأیید: محدودیت دقیقه‌ای IP |
| پایان قرارداد | روز پایان: یادآوری مهم «پاک کردن رمزها» به `credentials.manage` و «عوض کردن رمز / برداشتن دسترسی Business Suite» به مشتری؛ فقط وقتی پکیج فعال دیگری نیست (تست) |
| پیام‌های انقضا | روزها از پنل (۱ تا ۶۰، حداکثر ۶) + روز آخر + تمام شدن سهمیه؛ Job دو بار در روز = یک پیام (تست)؛ جاافتادن روزها = فقط نزدیک‌ترین یادآوری |
| درخواست تمدید | فقط کاربر پورتال؛ روزی یک بار؛ توضیح حداکثر ۵۰۰ کاراکتر |

یافته‌ی High/Critical: **ندارد**.

یادآوری عملیاتی: `VAULT_MASTER_KEY` را جدا از بکاپ‌های سرور (مثلاً در گاوصندوق رمز مدیر) نگه دارید؛ بدون آن رمزهای ذخیره‌شده دیگر باز نمی‌شوند.
