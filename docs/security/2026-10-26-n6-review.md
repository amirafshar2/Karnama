# بررسی امنیتی N6 (گفتگو) — ۴ آبان ۱۴۰۵

| موضوع | نتیجه |
|---|---|
| چه کسی با چه کسی | مدیر (`chat.groups.manage`) با همه؛ کارگر (`chat.use`) با مدیرها و فقط اگر در تنظیمات روشن باشد با همکار؛ مشتری فقط با مدیرها، هیچ‌وقت با کارگر یا در گروه (تست) |
| عضویت | هر خواندن/نوشتن/ویرایش/فایل/جستجو با عضویت چک می‌شود؛ غیرعضو → ۴۰۴ (تست) |
| گفتگوی کار | فقط کارمندی که آن سفارش را می‌بیند (همان قانون دید سفارش)؛ مشتری ۴۰۳ (تست) |
| ویرایش و حذف | ویرایش فقط نویسنده و تا ۱۵ دقیقه (تست ۴۰۳/۴۰۹)؛ حذف نرم، محتوا دیگر برگردانده نمی‌شود (تست)؛ مدیر در گروه‌ها می‌تواند حذف کند (Audit) |
| پیام تکراری | `ClientKey` یکتا در هر گفتگو: ارسال دوباره بعد از قطعی = یک پیام (تست) |
| فایل | Magic Bytes (HTML/SVG/اسکریپت رد، تست)؛ عکس ≤۳MB (کوچک‌سازی در گوشی)، صوت ≤۲ دقیقه و ≤۳MB (تست)، فایل ≤۲۰MB؛ ذخیره در پوشه‌ی خصوصی بیرون از وب؛ دریافت فقط برای اعضا با `nosniff`، غیر عکس/صوت همیشه دانلود (نه نمایش در مرورگر) |
| لایو | رویداد `chat` مثل اعلان خصوصی است: فقط به کانال خود اعضا (نه گروه مدیرها) و فقط شناسه؛ «در حال نوشتن» فقط به اعضا و ذخیره نمی‌شود |
| اعلان | حداکثر یک اعلان در ساعت برای هر گفتگو و هر نفر؛ بی‌صدا کردن گفتگو |
| مرورگر | `Permissions-Policy` میکروفون/دوربین/مکان فقط برای همان دامنه؛ `media-src 'self' blob:`؛ اندروید: `RECORD_AUDIO` فقط هنگام زدن دکمه‌ی ضبط پرسیده می‌شود |

یافته‌ی High/Critical: **ندارد**.

اصلاح جانبی: سرتیتر `Permissions-Policy` قبلاً دوربین و مکان را برای خود سایت هم می‌بست (`camera=()`، `geolocation=()`)؛ حالا `(self)` است تا اسکن QR و حضور با مکان در نسخه‌ی وب هم کار کند.
