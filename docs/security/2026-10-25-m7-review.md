# بررسی امنیتی M7 (اندروید، دانلود امضاشده، دیپلوی) — ۳ آبان ۱۴۰۵

## اندروید (MASVS v2)

| کنترل | نتیجه |
|---|---|
| MASVS-STORAGE | توکن تمدید در Keystore (`@aparajita/capacitor-secure-storage`)؛ توکن دسترسی فقط در حافظه؛ `allowBackup=false` + `data_extraction_rules` (هیچ داده‌ای در بکاپ ابری یا انتقال گوشی) |
| MASVS-NETWORK | `usesCleartextTraffic=false`، فقط CAهای سیستم (CA نصب‌شده توسط کاربر برای شنود پذیرفته نمی‌شود)، HTTP فقط برای امولاتور `10.0.2.2` |
| MASVS-PLATFORM | فقط مجوزهای لازم (دوربین، مکان لحظه‌ای، اعلان)؛ مکان فقط لحظه‌ی ورود (بدون پس‌زمینه)؛ پیوندهای بیرونی در مرورگر سیستم؛ لینک اعلان فقط مسیر داخلی |
| MASVS-CODE | اشکال‌زدایی WebView فقط با `KARNAMA_DEBUG=1`؛ `debuggable false` در Release؛ نسخه‌ی پلاگین‌ها ثابت و بدون اسکریپت نصب |
| MASVS-AUTH | ورود همان OTP/۲FA سرور؛ خروج = حذف توکن از Keystore و باطل‌شدن در سرور |
| MASVS-RESILIENCE | تشخیص مکان جعلی (پرچم mock، اپ جعل، جهش ناممکن) → ورود «نیازمند بررسی»؛ Obfuscation (R8) بعد از اولین بیلد موفق در Android Studio روشن شود |
| اسکن APK | با MobSF قبل از هر انتشار (`docs/MOBILE.md`) — اینجا امکان بیلد APK نبود (دسترسی به مخزن‌های گوگل) |

## سرور

| موضوع | نتیجه |
|---|---|
| دانلود امضاشده | توکن Data Protection با انقضای ۱۰ دقیقه، وابسته به فایل و کاربر؛ کاربر غیرفعال = لینک باطل؛ دست‌کاری = ۴۰۴ (تست)؛ Range پشتیبانی (تست)؛ `no-store`، `sandbox`، `no-referrer`؛ توکن در لاگ ثبت نمی‌شود (`/files/dl/***`) |
| ساختن لینک | فقط کسی که خودِ فایل را می‌تواند بخواند (تست ۴۰۴ برای دیگران) |
| کانتینرها | اجرا با کاربر غیر root، API و Worker فقط‌خواندنی، Postgres/Redis بدون پورت بیرونی، رمزها فقط در `deploy/.env.prod` (در گیت نیست) |
| مهاجرت دیتابیس | فقط اسکریپت بازبینی‌شده‌ی idempotent؛ مهاجرت خودکار در Production خاموش |
| بکاپ | روزانه + تست بازگردانی ماهانه |
| وابستگی‌ها | `npm audit`: ۰ آسیب‌پذیری در وب؛ در `mobile/` فقط ابزار CLI (برای iOS) هشدار متوسط دارد که در بیلد اندروید استفاده نمی‌شود |

## کارایی (بخش سخت‌سازی)

- تابلوی کار: ۵۲ → ۱۶۲ درخواست در ثانیه روی ۲ هسته (همراه با دیتابیس و ابزار تست روی همان ماشین) با حذف ستون‌های بزرگ JSON از کوئری‌های کمکی؛ همین اصلاح در ۸ جای دیگر.

- تست بار هزار کاربر: اسکریپت `tests/load/k6-1000.js` برای اجرا روی سرور آزمایشی (اینجا k6 در دسترس نبود).
