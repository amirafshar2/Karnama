# بررسی امنیتی N2 (دستگاه حضور) و N11 (دوربین) — ۵ آبان ۱۴۰۵

مدل دستگاه اثر انگشت و دوربین‌ها هنوز مشخص نیست. هر دو بخش با استانداردهای عمومی ساخته شده‌اند: ZKTeco ADMS و خروجی Excel/CSV برای دستگاه، RTSP/ONVIF و MediaMTX برای دوربین. وقتی مدل‌ها مشخص شد، فقط تنظیمات دقیق می‌شود.

## N2 — دستگاه اثر انگشت / چهره

| موضوع | نتیجه |
|---|---|
| ورود دستگاه | `/iclock/*` بدون حساب کاربری است (پروتکل دستگاه)، پس فقط شماره‌ی سریال ثبت‌شده و فعال **و** فقط از IP مجاز (IP دستگاه یا «اینترنت دفتر») جواب می‌گیرد؛ بقیه 403 خالی بدون توضیح (تست) |
| اندازه و تعداد | بدنه حداکثر ۲۵۶ کیلوبایت (413، تست)، حداکثر ۵۰۰۰ ردیف در هر ارسال، محدودیت ۱۲۰ درخواست در دقیقه برای هر IP، و در Caddy فقط مسیر `/iclock` روی زیردامنه‌ی جدا |
| داده‌ی زیستی | به دستگاه گفته می‌شود فقط AttLog بفرستد؛ جدول‌های FINGERTMP/USERINFO/ATTPHOTO/OPERLOG بی‌آن‌که ذخیره شوند «OK» می‌گیرند (تست). فقط شماره‌ی فرد و زمان ذخیره می‌شود |
| تکرار | (دستگاه، شماره، ثانیه) یکتا در دیتابیس؛ ارسال دوباره یک بار ثبت می‌شود (تست)؛ دو بار زدن در ۲ دقیقه نادیده |
| نظم زمانی | ثبتی که قدیمی‌تر از آخرین ثبت همان فرد باشد شیفت را عوض نمی‌کند و برای بررسی مدیر علامت می‌خورد |
| ساعت دستگاه | اختلاف بیش از ۲ دقیقه اندازه‌گیری و روزی یک بار به مدیر خبر داده می‌شود (تست)؛ «همگام‌سازی ساعت» دستور در صف دستگاه می‌گذارد (تست) |
| نگاشت شماره | فقط `devices.manage`؛ هر شماره یک نفر و هر نفر یک شماره (ایندکس یکتا، 409 تست)؛ Audit |
| فایل | xlsx/csv تا ۵ مگابایت و ۲۰٬۰۰۰ ردیف، پیش‌نمایش قبل از ثبت؛ تاریخ خارج از یک سال گذشته رد می‌شود؛ روزهایی که شیفت دارند دست نمی‌خورند (تست) |

## N11 — دوربین مداربسته

| موضوع | نتیجه |
|---|---|
| شبکه | دوربین/NVR هرگز روی اینترنت باز نمی‌شوند؛ جعبه‌ی دفتر با WireGuard **خروجی** به سرور وصل است؛ API و RTSP جعبه فقط روی نشانی تونل |
| نشانی دوربین | فقط `rtsp/rtsps` به IP داخلی (10/8، 172.16/12، 192.168/16) — جلوی SSRF به اینترنت (تست)؛ نشانی و رمز با گاوصندوق (AES-256-GCM، AAD = شناسه‌ی دوربین) ذخیره و هرگز برگردانده نمی‌شود، فقط شکل پوشانده (تست) |
| دیدن | عکس و زنده فقط `cctv.view` (403 تست)؛ عکس هر دوربین ۱۰ ثانیه مشترک بین بیننده‌ها (تست) |
| زنده | توکن ۵ دقیقه‌ای فقط برای همان مسیر؛ قلاب احراز MediaMTX فقط از نشانی تونل (403 از جای دیگر)، `read` با توکن معتبر همان دوربین، بقیه (publish، مسیر دیگر، توکن جعلی یا منقضی) 401 (تست)؛ ۲ دقیقه بی‌حرکتی = قطع |
| Audit | شروع و پایان هر تماشای زنده با نام، دوربین و مدت (تست)؛ افزودن/ویرایش/حذف دوربین |
| اخلاق | افزودن دوربین بدون تأیید «فقط فضای کار + تابلو» ممکن نیست (422 تست)؛ پخش فقط تصویر (WebRTC فقط video)، بدون صدا؛ ضبط روی NVR دفتر |
| هشدار | دوربین قطع‌شده یک بار برای هر قطعی به مدیر خبر داده می‌شود (تست) |
| مرورگر | آدرس پخش در CSP (`connect-src`) فقط با `NEXT_PUBLIC_CCTV_BASE`؛ در Caddy فقط مسیر `/cam-…/whep` |

یافته‌ی High/Critical: **ندارد**.
