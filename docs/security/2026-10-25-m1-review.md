# بررسی امنیتی M1 — ۳ آبان ۱۴۰۵

**اسکیل‌های این مرحله:** ۱ و ۲ (بررسی امنیتی کد مرحله، OWASP/ASVS)، ۳ (تحلیل ایستا)، ۴ (پیش‌فرض‌های ناامن)، ۷ (GitHub Actions).
**روش:** پلاگین‌ها روی کامپیوتر امیر نصب نیستند و از محیط ساخت به semgrep.dev دسترسی نبود؛ پس:
- بررسی مستقل با یک بازبین جدا که کد را بدون نظر سازنده خواند (لنزهای اسکیل ۱، ۲، ۴، ۷).
- اسکیل ۳: **CodeQL** در `.github/workflows/codeql.yml` (C# + TypeScript، `security-extended`) روی هر PR.
- `dotnet list package --vulnerable` و `npm audit` → **۰ آسیب‌پذیری**؛ در CI پکیج آسیب‌پذیر = build قرمز
  (در همین مرحله `Newtonsoft.Json 11.0.1` که Hangfire می‌آورد، build را قرمز کرد و به ۱۳.۰.۴ ارتقا یافت).

**بدون یافته (بررسی شد):** JWT (HS256 ثابت، ۱۵ دقیقه، audience جدا برای ۲FA)، Refresh هش‌شده در کوکی HttpOnly/Secure/SameSite=Strict با مسیر محدود، توکن هاب فقط روی `/hubs` و ثبت‌نشدن query در لاگ، HMAC کد OTP و مقایسه‌ی ثابت‌زمان، ۲FA اجباری مالک، `roles.manage:All` روی همه‌ی endpointهای نقش، نبود تزریق (فقط LINQ)، CORS لیست سفید، کد نصب ثابت‌زمان و تراکنشی، نبود Stack Trace، Actions با SHA ثابت و `contents: read` و `persist-credentials: false`.
