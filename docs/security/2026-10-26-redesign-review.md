# بازبینی امنیتی — بازطراحی کامل سایت، پنل و اپ (۴ آبان ۱۴۰۵)

دامنه: ویدیو و عکس‌های سربرگ صفحه‌ی اصلی (آپلود از پنل)، رسانه‌ی نمونه‌ی دمو، کامپوننت‌های 21st.dev، صفحه‌ی ورود جدید.

| موضوع | بررسی | نتیجه |
|---|---|---|
| آپلود ویدیو | فقط با دسترسی `content.manage` همه؛ محدودیت نرخ `Heavy`؛ سقف ۱۸ مگابایت (زیر سقف ۲۰ مگابایتی Caddy) هم در Kestrel (`RequestSizeLimit`/`MultipartBodyLengthLimit`) و هم هنگام نوشتن فایل (شمارش بایت، نه اعتماد به `Content-Length`) | ✅ |
| نوع فایل | تشخیص با magic bytes: MP4 (`ftyp` در بایت ۴) و WebM (`1A 45 DF A3`)؛ پسوند و نام فایل کاربر نادیده گرفته می‌شود؛ نام تصادفی GUID | ✅ |
| فایل ناقص | اگر طول دریافتی با طول اعلام‌شده نخواند، فایل پاک و خطا برگردانده می‌شود | ✅ |
| مسیر فایل | شناسه فقط با regex `^(…|site)/[0-9a-f]{32}\.(png|jpg|webp|mp4|webm)$` باز می‌شود و مسیر نهایی باید داخل ریشه‌ی ذخیره بماند (path traversal) | ✅ |
| محتوای صفحه‌ی اصلی | `HeroVideo` / `HeroPoster` / `HeroImages` فقط شناسه‌ی فایلی است که خودمان ذخیره کرده‌ایم (اعتبارسنج regex)؛ لینک آزاد پذیرفته نمی‌شود ⇒ نه hotlink، نه XSS از راه URL، نه SSRF. تست: `Hero_video_and_photos_are_uploaded_checked_and_served_with_ranges` | ✅ |
| ارسال ویدیو | `enableRangeProcessing` برای پخش در Safari/اندروید؛ `X-Content-Type-Options: nosniff` سراسری؛ کش `immutable` چون نام‌ها تکرار نمی‌شوند | ✅ |
| CSP | `media-src` فقط `'self' blob:` و آدرس API خودمان (برای اپ اندروید)؛ چیز دیگری اضافه نشد | ✅ |
| کامپوننت‌های 21st | کد خوانده و بازنویسی شد؛ هیچ اسکریپت، فونت یا تصویری از دامنه‌ی بیرونی (cdn.21st.dev، cloudfront) بارگذاری نمی‌شود؛ وابستگی تازه‌ی npm اضافه نشد | ✅ |
| کلید 21st | فقط در محیط محلی سازنده؛ در ریپو، کد و مستندات نیست | ✅ |
| رسانه‌ی دمو | عکس‌ها و ویدیوی نمونه داخل اسمبلی Infrastructure جاسازی شده‌اند و فقط در حالت `Seed:Mode=Demo` نوشته می‌شوند؛ نصب خالی آن‌ها را نمی‌گیرد. تولید: هوش مصنوعی (بدون چهره‌ی واقعی مشتری، بدون لوگو) | ✅ |
| صفحه‌ی ورود | فقط `/api/v1/public/site/home` (داده‌ی عمومی، بدون توکن) برای ویدیوی پس‌زمینه خوانده می‌شود؛ خطا نادیده گرفته می‌شود | ✅ |
| حرکت و دسترس‌پذیری | `prefers-reduced-motion`: ویدیو پنهان، انیمیشن‌ها خاموش؛ بدون جاوااسکریپت همه‌ی بخش‌ها دیده می‌شوند؛ ویدیو بی‌صدا و `aria-hidden` | ✅ |
| حریم خصوصی | ممیزی: `site.videoUploaded` / `site.imageUploaded` با شناسه‌ی فایل | ✅ |

باقی‌مانده: آپلود قابل‌ازسرگیری برای ویدیوهای بزرگ‌تر از ۱۸ مگابایت لازم نیست (حلقه‌ی پس‌زمینه کوتاه است)؛ اگر لازم شد، همان مسیر تکه‌ای فایل‌ها استفاده شود.
