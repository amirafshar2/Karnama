# بررسی امنیتی M5 (غیبت و مرخصی) — ۳ آبان ۱۴۰۵

| موضوع | نتیجه |
|---|---|
| ثبت مرخصی برای دیگران | فقط با `attendance.approve:All`؛ همکار باید از کارکنان باشد (تست) |
| تأیید مرخصی/غیبت خود | ممنوع در Domain (`LeaveRequest.Decide`، `Absence.Decide`) (تست) |
| دیدن مرخصی/غیبت دیگران | بدون `attendance.view:All` یا `approve` فقط ردیف‌های خود شخص؛ تقویم هم فقط ردیف خودش |
| گزارش حقوق و Excel | فقط `attendance.view:All` (تست ۴۰۳)؛ Excel ضد Formula Injection |
| ثبت دلیل غیبت | فقط صاحب غیبت؛ بعد از تبدیل به تأخیر یا تصمیم مدیر بسته است |
| تکرار Job تشخیص غیبت | ایندکس یکتای (کاربر، روز) + اجرای دوم چیزی نمی‌سازد (تست) |
| مدرک مرخصی | فقط فایلی که خود شخص آپلود کرده؛ نبود مدرک مانع نیست ولی به مدیر نشان داده می‌شود |
| هم‌پوشانی درخواست‌ها | رد با ۴۰۹ (تست) |
| مانده‌ی مرخصی | از درخواست‌های تأییدشده محاسبه می‌شود، فیلد قابل ویرایش ندارد |
