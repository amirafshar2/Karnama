# بررسی امنیتی N8 (گزارش بازه و امتیاز کارگرها) — ۴ آبان ۱۴۰۵

| موضوع | نتیجه |
|---|---|
| دید گزارش | `reports.view:All` همه را می‌بیند؛ کارگر (`reports.view:Own` یا `attendance.self`) فقط خودش، حتی اگر شناسه‌ی همکار را در آدرس بگذارد (پارامتر `user` نادیده گرفته می‌شود؛ جزئیات همکار → ۴۰۴) (تست IDOR) |
| خروجی اکسل | فقط `reports.export:All`؛ کارگر ۴۰۳ (تست). فایل در حافظه ساخته می‌شود و جایی ذخیره نمی‌شود |
| دید امتیاز | `scores.view:Own` فقط امتیاز خودش؛ اگر مدیر «رتبه‌بندی برای همه» را روشن کند، بقیه فقط نام، امتیاز کل و نشان را می‌بینند، **بدون** جزئیات و شاخص‌ها (تست). روند ۶ ماه همکار → ۴۰۴ (تست) |
| انصاف | به‌موقع بودن با «اولین تحویل کارگر» (`FirstSubmittedAt`) سنجیده می‌شود، نه تأیید دیر مشتری (تست)؛ کمتر از حداقل نمونه → «داده‌ی کافی نیست» به‌جای عدد (تست)؛ هر شاخص توضیح «چرا» دارد |
| وزن‌ها | فقط `scores.configure:All`؛ جمع صفر یا بازه‌ی نامعتبر ۴۲۲؛ هر تغییر Audit با مقدار قبل و بعد (تست) |
| ستاره | ستاره‌ی مدیر فقط با `work.review:All` و فقط روی کار تمام‌شده (۴۰۳/۴۰۹/۴۲۲ تست)؛ ستاره‌ی مشتری فقط هنگام تأیید کار خودش در پرتال، ۱ تا ۵ |
| داده‌ی دمو | تاریخچه‌ی ۳۵ روزه فقط در نسخه‌ی دمو ساخته می‌شود (نصب خالی بی‌تأثیر) |
| چاپ/PDF | با چاپ مرورگر؛ منو و دکمه‌ها در چاپ پنهان می‌شوند؛ داده‌ی اضافه‌ای به مرورگر نمی‌رود |

یافته‌ی High/Critical: **ندارد**.
