# راه‌اندازی ربات تلگرام (سرور کوچک خارج از ایران)

تلگرام در ایران فیلتر است؛ برای همین یک سرویس کوچک (`Karnama.TelegramGateway`) روی سروری **بیرون از ایران** اجرا می‌شود. این سرویس فقط پیام‌های ربات را با امضای امن به سرور ایران می‌رساند و دستورهای سرور ایران را به تلگرام می‌دهد. **هیچ داده‌ی حساسی (شماره، مبلغ، رمز) اینجا ذخیره نمی‌شود**؛ فقط صف موقت پیام‌ها. فایل‌ها هم از این سرور رد نمی‌شوند (فقط پیش‌نمایش‌های خیلی کوچک).

## ۱. ساخت ربات و کانال آرشیو
1. در تلگرام به `@BotFather` پیام بدهید → `/newbot` → توکن ربات را جای امنی یادداشت کنید.
2. یک **کانال خصوصی** بسازید (مثلاً «آرشیو فایل‌های کارنما») و ربات را **ادمین** آن کنید.
3. شناسه‌ی کانال را بگیرید (عددی مثل `-1001234567890`؛ مثلاً یک پیام از کانال را برای `@userinfobot` فوروارد کنید).

## ۲. سرور خارج
- یک سرور لینوکس کوچک (۱ هسته، ۵۱۲ مگابایت کافی است) با Docker و یک دامنه یا زیردامنه (مثلاً `tg.example.com`) که به IP آن اشاره کند.
- روی کامپیوتر خودتان: `python3 tools/new-env.py --gateway` → فایل `deploy/gateway/.env` ساخته می‌شود و یک مقدار `TELEGRAM_GATEWAY_SECRET` چاپ می‌شود (برای سرور ایران).
- در `deploy/gateway/.env`: `GATEWAY_DOMAIN`، `Gateway__PublicUrl`، `Telegram__BotToken` و `Gateway__IranApiUrl` (آدرس API ایران، با https) را پر کنید.
- پوشه‌ی پروژه را روی سرور بگذارید و: `cd deploy/gateway && docker compose up -d --build`
- سرویس هنگام شروع خودش Webhook تلگرام را ثبت می‌کند. سلامت: `https://tg.example.com/health`.

## ۳. سرور ایران
در `deploy/.env.prod` این‌ها را پر کنید و سرویس‌ها را دوباره بالا بیاورید:
```
TELEGRAM_BOT_USERNAME=نام_ربات_بدون_@
TELEGRAM_GATEWAY_URL=https://tg.example.com
TELEGRAM_GATEWAY_SECRET=همان مقدار چاپ‌شده
TELEGRAM_ARCHIVE_CHAT_ID=-1001234567890
```

## ۴. استفاده
- هر نفر در «حساب من» ← «اتصال تلگرام» را می‌زند (کد یک‌بارمصرف ۱۰ دقیقه‌ای؛ هیچ‌وقت از شماره‌ی تلفن برای شناسایی استفاده نمی‌شود). قطع اتصال: `/stop` یا از پروفایل.
- فیلمبردار فایل را برای ربات می‌فرستد → در کانال آرشیو کپی می‌شود → برای ادمین‌ها (مجوز `media.inbox`) با دکمه‌ی «سپردن به…» فرستاده می‌شود → ربات از فرستنده می‌پرسد «برای کدام کار است؟».
- ادمین از «صندوق فایل‌ها» در پنل یا از داخل تلگرام فایل را به کارگر یا مشتری می‌سپارد؛ ربات آن را مستقیم در تلگرام گیرنده می‌فرستد.

## امنیت
- Webhook تلگرام: مسیر مخفی + `secret_token`.
- بین این سرور و ایران: HTTPS + امضای HMAC-SHA256 + زمان‌مهر ۵ دقیقه‌ای + رد درخواست تکراری؛ هر پیام تلگرام فقط یک بار ثبت می‌شود (`update_id`).
- اگر اینترنت بین‌الملل قطع شود، پیام‌ها روی دیسک همین سرور صف می‌شوند و بعد از وصل شدن فرستاده می‌شوند؛ دستورهای سرور ایران هم در Outbox ایران می‌مانند.
- فقط این متدهای تلگرام قابل فراخوانی‌اند: `sendMessage`، `copyMessage`، `answerCallbackQuery`، `editMessageReplyMarkup`.

## بله
ربات بله داخل ایران کار می‌کند و اعلان‌ها و اتصال حساب از امروز با آن کار می‌کنند. **فایل از طریق بله** فقط وقتی روشن شود (`Notify__BaleFiles=true` و `Notify__BaleArchiveChatId`) که در مستندات رسمی بله تأیید کنید متد `copyMessage` و سقف حجم فایل برای ربات شما پشتیبانی می‌شود.
