# راه‌اندازی دوربین‌ها (N11)

دوربین‌ها و دستگاه ضبط (NVR) **هرگز** روی اینترنت باز نمی‌شوند. روی مودم دفتر هیچ پورتی باز نمی‌کنیم.
یک کامپیوتر کوچک در دفتر (مینی‌پی‌سی یا رزبری‌پای ۴ به بالا) تصویر دوربین‌ها را می‌گیرد. همین کامپیوتر از داخل دفتر یک تونل امن (WireGuard) به سرور می‌زند.

```
دوربین‌ها ──(شبکه‌ی دفتر)──▶ جعبه‌ی دفتر (MediaMTX) ══ تونل WireGuard ══▶ سرور ──▶ مرورگر کاربر
```

## چه چیزی لازم است

- یک مینی‌پی‌سی یا رزبری‌پای با Ubuntu یا Debian، با کابل به شبکه‌ی دفتر وصل باشد.
- نشانی RTSP هر دوربین. نمونه‌ها:
  - **هایک‌ویژن:**
    - کیفیت اصلی: `rtsp://admin:رمز@192.168.1.64:554/Streaming/Channels/101`
    - کیفیت کم: `rtsp://admin:رمز@192.168.1.64:554/Streaming/Channels/102`
  - **داهوا:**
    - کیفیت اصلی: `rtsp://admin:رمز@192.168.1.108:554/cam/realmonitor?channel=1&subtype=0`
    - کیفیت کم: `subtype=1`
  - **NVR:** همان الگوها برای هر کانال (`Channels/201`، `channel=2` و …).
  - **برندهای داخلی:** معمولاً ONVIF دارند. با برنامه‌ی «ONVIF Device Manager» نشانی RTSP را پیدا کنید.
- برای هر دوربین یک کاربر «فقط مشاهده» در خود دوربین یا NVR بسازید و رمز ادمین را استفاده نکنید.

## ۱. تونل

1. روی هر دو دستگاه WireGuard را نصب کنید: `apt install wireguard`.
2. روی هر دو کلید بسازید: `wg genkey | tee key | wg pubkey > key.pub`.
3. فایل‌های نمونه را کپی و پر کنید:
   - سرور: از `wg-server.conf.example` به `/etc/wireguard/wg0.conf`.
   - جعبه‌ی دفتر: از `wg-office.conf.example` به `/etc/wireguard/wg0.conf`.
4. روی هر دو اجرا کنید: `systemctl enable --now wg-quick@wg0`.
5. روی سرور بزنید `ping 10.66.0.2`. باید جواب بدهد.
6. روی سرور در دیوار آتش این سه پورت را باز کنید:
   - **UDP 51820:** برای تونل.
   - **UDP و TCP 8189:** برای تصویر زنده.
   - **8081:** فقط از داخل تونل. مثلاً: `ufw allow in on wg0 to any port 8081`.

## ۲. MediaMTX روی جعبه‌ی دفتر

1. آخرین نسخه‌ی MediaMTX را از github.com/bluenviron/mediamtx بگیرید.
2. فایل `mediamtx.yml` همین پوشه را کنارش بگذارید و `<SERVER_PUBLIC_IP>` را عوض کنید.
3. آن را به‌عنوان سرویس systemd اجرا کنید.

دوربین‌ها را **دستی** در این فایل ننویسید. کارنما آن‌ها را از طریق تونل اضافه می‌کند.

## ۳. سرور

در `deploy/.env.prod` این مقدارها را بگذارید:

- `CCTV_DOMAIN`: زیردامنه‌ی تصویر، مثلاً `cctv.example.ir`.
- `CCTV_PUBLIC_URL`: همین نشانی با https، یعنی `https://cctv.example.ir`.
- `CCTV_INTERNAL_PASSWORD`: یک رمز طولانی تصادفی. این رمز فقط بین سرور و جعبه‌ی دفتر است.

بعد سرویس‌ها را بالا بیاورید:

```
docker compose -f deploy/docker-compose.prod.yml --env-file deploy/.env.prod up -d --build
```

## ۴. در پنل

1. منو «دوربین‌ها» را باز کنید و «افزودن دوربین» را بزنید.
2. نام، نشانی RTSP اصلی و کم‌حجم را وارد کنید.
3. تأیید کنید که دوربین فقط فضای کار را می‌بیند.
4. در چند ثانیه عکس اول می‌آید و وضعیت «روشن» می‌شود.

| کار | دسترسی لازم |
|---|---|
| دیدن تصویر | `cctv.view` |
| افزودن و ویرایش دوربین | `cctv.manage` |

هر بار باز کردن تصویر زنده با نام، دوربین، زمان و مدت در گزارش امنیتی (Audit) ثبت می‌شود.

## اخلاق و قانون

- دوربین فقط در فضای کار باشد. هیچ دوربینی در سرویس بهداشتی یا فضای خصوصی نصب نشود.
- تابلوی «این محیط دوربین دارد» را نصب کنید.
- صدا هرگز پخش نمی‌شود.
- ضبط روی NVR خود دفتر می‌ماند، نه روی سرور.
